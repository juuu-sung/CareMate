# Development Checklist

GitHub Issues와 Projects에서 바로 사용할 수 있는 개발 체크리스트입니다.

## 1. MVP Epic 단위

### Epic 1. 사용자 앱 기본 흐름

- [ ] 홈 화면 구조 확정
- [ ] 대화 화면 버튼 기반 음성 흐름 구현
- [ ] 복약 화면 API 연결
- [ ] 일정 화면 API 연결
- [ ] SOS 요청 흐름 연결

### Epic 2. 보호자 앱 기본 흐름

- [ ] 대시보드 집계 API 연결
- [ ] 알림 이력 화면 구현
- [ ] 위치 확인 화면 구현
- [ ] 돌봄 모드 설정 화면 구현
- [ ] 보호자 연결 정보 화면 구현

### Epic 3. 백엔드 기본 기능

- [ ] 대화 API 실제 LLM 연동
- [ ] 복약 조회 API DB 연결
- [ ] 일정 조회 API DB 연결
- [ ] 보호자 대시보드 집계 로직 DB 연결
- [ ] 위치 저장 및 최신 위치 조회 API 고도화

### Epic 4. 안전 및 규칙 엔진

- [ ] 체크인 누락 규칙 확정
- [ ] 복약 미응답 규칙 확정
- [ ] 일정 미응답 규칙 확정
- [ ] SOS 우선 알림 규칙 확정
- [ ] 보호자 알림 전송 시점 확정

### Epic 5. 인프라와 실행 환경

- [ ] PostgreSQL 컨테이너 실행 확인
- [ ] Alembic 초기 마이그레이션 적용
- [ ] `.env` 설정 문서화
- [ ] 로컬 개발 실행 절차 검증

## 2. Issue 체크리스트

각 기능 이슈는 아래 순서로 관리합니다.

- [ ] 요구사항 정의
- [ ] API 또는 화면 계약 확인
- [ ] 구현 범위 확정
- [ ] 작업 시작
- [ ] 검증 완료
- [ ] 문서 반영
- [ ] 리뷰 가능 상태

## 3. Project Board 컬럼 제안

- `Backlog`
- `Ready`
- `In Progress`
- `Review`
- `Done`

## 4. 우선순위 규칙

- `P0`: 데모나 핵심 흐름이 막히는 작업
- `P1`: MVP 완성에 직접 필요한 작업
- `P2`: 품질 개선 또는 확장 준비 작업

4. 위치 조회 화면 연결
